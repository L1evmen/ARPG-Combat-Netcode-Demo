# CombatV2 连招系统 —— 使用说明

## 快速开始

1. 在玩家 GameObject 上挂载 `ComboManager` 组件。
2. 在 Inspector 中拖入 `Animator`、`PlayerController`、`WeaponBase` 引用。
3. 确保武器预制体上已挂载 `HitBox` 组件（碰撞器设为 Trigger）。
4. 在 Animator 中创建对应动画状态（`LightAttack1`、`LightAttack2` 等），**不需要连线过渡**。
5. 运行游戏，左键轻击、右键蓄力重击、右键+W 升龙斩。

## 目录结构

```
CombatV2/
├── ComboManager.cs       # 连招总管（MonoBehaviour）
├── ComboAction.cs        # 招式抽象基类
├── ComboContext.cs       # 共享上下文
├── ComboInputType.cs     # 输入类型枚举
└── Actions/
    ├── LightAttack1.cs   # 轻击一段
    ├── LightAttack2.cs   # 轻击二段
    ├── LightAttack3.cs   # 轻击三段
    ├── ChargeHeavy.cs    # 蓄力重击
    ├── RisingSlash.cs    # 升龙斩
    ├── AirCombo.cs       # 空中连招
    ├── GroundSlam.cs     # 裂地劈
    └── DodgeAction.cs    # 闪避
```

## 如何添加新招式（例如：回旋斩）

**严格遵守 OCP：只新增文件，不改任何已有文件。**

### 步骤 1：创建新脚本

在 `Actions/` 目录下新建 `WhirlwindSlash.cs`：

```csharp
using UnityEngine;

namespace CombatV2.Actions
{
    /// <summary>
    /// 回旋斩 —— 360度范围攻击，命中后小幅击退敌人。
    /// 在轻击第三段或蓄力重击的取消窗口中，按重击+下方向发动。
    /// </summary>
    public class WhirlwindSlash : ComboAction
    {
        // ========== 必须重写 ==========

        public override string AnimName => "WhirlwindSlash";  // Animator 中的状态名
        public override float AnimLength => 1.0f;              // 动画时长（秒）
        public override int Damage => 28;                      // 基础伤害

        // ========== 可选重写（窗口配置） ==========

        public override float ComboWindowStart => 0.40f;
        public override float ComboWindowEnd => 0.80f;
        public override float HitboxStart => 0.10f;
        public override float HitboxEnd => 0.60f;

        public override bool CanBeCancelled => true;
        public override float CancelWindowStart => 0.55f;
        public override float ForwardSpeed => 2f;              // 旋转时前移

        // ========== 允许转入的招式（白名单） ==========

        public override bool CanTransitionTo(System.Type nextActionType)
        {
            return nextActionType == typeof(LightAttack1) ||
                   nextActionType == typeof(ChargeHeavy);
        }

        // ========== 生命周期 ==========

        public override void OnEnter(ComboContext ctx)
        {
            PlayAnim(ctx, 0.05f);
            // 可选：在此播放音效、粒子特效等
        }

        public override void OnUpdate(ComboContext ctx)
        {
            UpdateHitboxAuto(ctx);          // 自动管理 HitBox 开关
            ApplyForwardMovement(ctx);       // 前位移

            // 取消窗口内轻击 → 重新开始地面连段
            if (IsInCancelWindow(ctx) && ctx.HasBufferedLight())
            {
                ctx.ConsumeLight();
                RequestTransition<LightAttack1>(ctx);
                return;
            }

            CheckAnimEnd(ctx);              // 动画播完自动回空闲
        }

        public override void OnExit(ComboContext ctx)
        {
            ctx.DisableHitBoxes();
            // 可选：清理特效等
        }
    }
}
```

### 步骤 2：在现有招式中开放入口

新招式要能被发动，需要在**已有招式**中添加入口条件。找到你希望作为前置的招式脚本，例如 `LightAttack3.cs`，在其 `CanTransitionTo` 中添加 `typeof(WhirlwindSlash)`：

```csharp
// LightAttack3.cs  —— 只改这一行，不改其他逻辑
public override bool CanTransitionTo(System.Type nextActionType)
{
    return nextActionType == typeof(LightAttack1) ||
           nextActionType == typeof(ChargeHeavy) ||
           nextActionType == typeof(RisingSlash) ||
           nextActionType == typeof(WhirlwindSlash);  // ← 新增
}
```

并在 `OnUpdate` 中添加入口条件：

```csharp
// 在 LightAttack3.OnUpdate 中新增：
if (IsInCancelWindow(ctx) && ctx.HeavyReleased && ctx.MoveInput.y < -0.5f)
{
    RequestTransition<WhirlwindSlash>(ctx);
    return;
}
```

### 步骤 3：完成

无需修改 `ComboManager`、`ComboAction` 基类或任何其他招式脚本。新招式即刻生效。

## 关键设计要点

| 要点 | 说明 |
|------|------|
| **动画控制** | 所有动画通过 `CrossFadeInFixedTime` 直接播放，不依赖 Animator 状态机连线 |
| **输入缓冲** | ComboManager 维护 0.25s 输入缓冲队列，支持宽松的连招手感 |
| **蓄力机制** | 按住右键蓄力，松开发动 ChargeHeavy；蓄力时长决定等级（L1/L2/L3），伤害与动画不同 |
| **浮空状态** | `ComboManager.IsEnemyAirborne` 由 RisingSlash 设为 true，GroundSlam 设为 false |
| **动作缓存** | 每种招式只创建一个实例，通过 `_actionCache` 复用，避免 GC 分配 |
| **移动锁定** | 招式期间自动设置 `InputController.MovementBlocked = true` |

## 需要在 Animator 中创建的动画（全部 13 个）

以下动画状态需要在 Animator Controller 中创建，命名必须与下表完全一致。**不需要状态机过渡连线**，系统通过 `CrossFadeInFixedTime` 按 Hash 直接播放。

### 移动待机（1 个）

| 动画状态名 | 触发时机 | 说明 |
|-----------|---------|------|
| `Locomotion` | 招式结束后自动切回 | BlendTree：Idle/Walk/Run，由 Speed 参数驱动。可在 Inspector 中修改 `_locomotionStateName` |

> 如果你的 Animator 中该状态叫 `StandMove`，在 ComboManager 的 Inspector 里把 Locomotion State Name 改为 `StandMove` 即可。

### 蓄力待机（1 个）

| 动画状态名 | 触发时机 | 说明 |
|-----------|---------|------|
| `ChargeHold` | 空闲时按住重击键 | 蓄力蓄能待机动画，由 ComboManager 直接播放 |

### 轻击连段（3 个，无位移）

| 动画状态名 | 对应脚本 | 说明 |
|-----------|----------|------|
| `LightAttack1` | LightAttack1.cs | 轻击一段 |
| `LightAttack2` | LightAttack2.cs | 轻击二段 |
| `LightAttack3` | LightAttack3.cs | 轻击三段（终结） |

### 蓄力重击（3 个，按蓄力等级）

| 动画状态名 | 蓄力时间 | 伤害 | 说明 |
|-----------|---------|------|------|
| `ChargeHeavy_L1` | 0.4 ~ 1.07s | 40 | 短按松开 |
| `ChargeHeavy_L2` | 1.07 ~ 1.73s | 60 | 中程蓄力 |
| `ChargeHeavy_L3` | 1.73 ~ 2.0s | 80 | 满蓄力 |

> 蓄力等级由 `ComboManager._chargeThreshold`(0.4s) 和 `_maxChargeTime`(2.0s) 控制，3 段自动均分。

### 特殊招式（5 个）

| 动画状态名 | 对应脚本 | 说明 |
|-----------|----------|------|
| `RisingSlash` | RisingSlash.cs | 升龙斩（重击+上） |
| `AirCombo1` | AirCombo.cs | 空中连招第一轮 |
| `AirCombo2` | AirCombo.cs | 空中连招第二轮 |
| `AirCombo3` | AirCombo.cs | 空中连招第三轮（循环后回到1） |
| `GroundSlam` | GroundSlam.cs | 裂地劈 |
| `Dodge` | DodgeAction.cs | 闪避（Shift触发，不可打断） |

> 共需创建 **13 个**动画状态（不含 Animator 已有的 Locomotion/StandMove）。

## 设置系统接口（预留扩展）

以下接口和类为后续的键位修改、音量控制等功能预留了扩展点：

### 接口一览

| 文件 | 类型 | 说明 |
|------|------|------|
| `ICombatInputProvider.cs` | 接口 | 战斗输入抽象，ComboManager 依赖此接口而非硬件 |
| `DefaultCombatInputProvider.cs` | MonoBehaviour | 默认实现（鼠标左=轻击，右=重击，W=上，Shift=闪避） |
| `IAudioManager.cs` | 接口 | 音频管理抽象，音量控制 / BGM / SFX 播放 |
| `GameSettings.cs` | ScriptableObject | 设置数据容器（音量、键位、灵敏度、帧率等） |
| `SettingsManager.cs` | MonoBehaviour 单例 | 设置加载/保存/变更通知中枢 |

### 如何实现音量控制

```csharp
// 1. 创建 AudioManager，实现 IAudioManager
public class AudioManager : MonoBehaviour, IAudioManager
{
    [SerializeField] private AudioMixer _mixer;

    public void SetMasterVolume(float volume)
    {
        _mixer.SetFloat("MasterVolume", Mathf.Lerp(-80f, 0f, volume));
    }
    // ... 其余实现
}

// 2. 在 SettingsMenu UI 中订阅 SettingsManager 事件：
SettingsManager.Instance.OnMasterVolumeChanged += audio.SetMasterVolume;
SettingsManager.Instance.OnBGMVolumeChanged += audio.SetBGMVolume;
SettingsManager.Instance.OnSFXVolumeChanged += audio.SetSFXVolume;
```

### 设置持久化流程

```
[设置 UI] → SettingsManager.SetMasterVolume(0.5f)
          → PlayerPrefs.SetFloat(...)
          → PlayerPrefs.Save()
          → OnMasterVolumeChanged?.Invoke(0.5f)
          → [AudioManager] 收到事件，更新 AudioMixer
```

默认 GameSettings 资产通过 `Create → Game → Settings` 创建，放入 `Resources/` 目录。启动时自动加载并以 PlayerPrefs 覆盖用户修改的项。
